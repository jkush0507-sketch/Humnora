# Humnora

Humnora is an AI-powered emergency assistance platform connecting people who need help with nearby verified helpers and emergency service providers.

## Project Structure

- `apps/web` — Humnora Web Application
- `apps/mobile` — Humnora Android & iOS Application
- `backend` — Humnora Python Backend
- `docs` — Product, architecture and technical documentation

## Core Users

- Help Seeker
- Helper
- Organizations / Service Providers
- Administrators

## Core Technology

- Web: Next.js + TypeScript
- Mobile: Expo + React Native
- Backend: Python + FastAPI
- Database: PostgreSQL
- Cache / Realtime: Redis
- AI: Gemini
